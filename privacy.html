Privacy Policy

Last updated: October 28, 2026

Tool YouTube ("the app") is a private tool operated by its developer for managing the developer's own YouTube channels.

Data the app accesses

When the developer signs in with Google, the app uses the YouTube Data API and YouTube Analytics API, with the permissions the developer grants, to upload videos, schedule publishing, set thumbnails and captions, and read statistics of the developer's own channels.

How data is used and stored

Access tokens are stored only on the developer's own computer and are used solely to perform the actions above. The app does not sell, share, transfer or disclose any Google user data to third parties, and does not use it for advertising.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Stored tokens can be deleted by removing the token files from the developer's computer.
